# 🔍 Delitos Económicos en América Latina 2020-2023

**Dashboard académico interactivo** con 35 páginas de análisis sobre cinco categorías de delitos económicos en 20 países latinoamericanos.

- **Autor:** de la Serna, Juan Moises (UNIR) — ORCID: 0000-0002-8401-8018
